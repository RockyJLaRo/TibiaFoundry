What is Tibia Foundry?

Tibia Foundry is a desktop toolkit for working with the files of the Tibia game client. It began as the tool TibiaWiki editors use to extract images and data, and it has grown into one place for everything the client contains: every object, outfit, creature, house, map area, sound and item name.

It is made for TibiaWiki editors first, and is just as useful for fan-site and tool makers, Open Tibia developers and players who want to keep old client versions. You don't need to know the client's file formats: pick what you want, preview it, and export it.

Ready for the wiki

File names, GIF timing, outfit sheets and data exports follow TibiaWiki's needs.

Your name in every image

Exported PNGs and GIFs carry your creator name in their metadata, with no visible watermark.

Careful with your files

It never writes into the Tibia client, asks before replacing a file and keeps backups.

What you can do

Twenty pages, in three groups: client data, tools, and managing your clients.

Sprites, outfits and creatures

Browse every object, outfit, effect and missile, and every monster and boss. Export animated GIFs with the real frame timing, color outfits with addons and mounts, and build outfit sheets for TibiaWiki.

Maps and houses

Render any house, one floor or all, as a PNG. Extract map tiles and build high-resolution maps of the game world at 25, 50 or 100 % zoom. Export areas, subareas and NPCs.

Item Catalog

Collect item names and IDs from the client, TibiaWiki, Open Tibia items.xml/items.otb and CSV files. Each name keeps its source; conflicts are shown, never merged silently. Export to CSV, JSON or Excel.

Sounds and game data

Play and extract the client's sounds and music as OGG or WAV. Export appearances, static data, areas and NPC trade tables as JSON or Lua.

Client archive and rebuild

Keep every Tibia client version you choose. Identical files are stored once, personal data is left out unless you include it, and any archived version can be rebuilt as a normal folder later.

Editors and converters

Edit client objects and sprites in the Assets Editor, change Qt resource files in the RCC Editor, and convert modern client assets to legacy Tibia.dat/Tibia.spr (10.98) for Open Tibia projects.

File Metadata: see and edit what's inside your files

A tool for the metadata of almost any file: titles, authors, copyright, keywords, dates, GPS positions, album and track tags, document properties and more. Inspect one file, edit many at once, compare them, or export a report.

  • Edit one file or hundreds. Select several files and type a value once, or build batch operations (set, remove, add or replace keywords, copy from a reference file) and preview them file by file before anything is written.
  • Every save is checked. Changes are written to a copy, read back and verified — the new values must be there and every other field unchanged — before the copy replaces the file. A failure leaves the file as it was.
  • Backups and honest results. Optional verified backups (restorable from Scripts → Backup and Restore), the modified date kept, files changed by another program never overwritten, and a result per file: saved, unchanged, not applicable or failed, with the reason.
  • Nothing removed silently. Removing authorship, copyright or GPS data is named before you confirm. Fields a format cannot store are refused and listed, never dropped.
  • Presets and reports. Save author, copyright and keywords as a preset; export CSV or JSON reports of any number of files.

Safe for your client and your files

Tibia Foundry only reads your Tibia installation. It never changes the client, never touches the running game, and never sends your data anywhere.

  • Read-only client. No tool writes into a Tibia client folder or the client archive; outputs there are refused.
  • No surprises with your files. Existing files are never replaced without asking, and replaced files go to a verified backup. File scripts preview every change and never delete.
  • Private by default. No account, no telemetry. The program goes online only when you import item data from TibiaWiki or use the optional asset download.
  • Personal data stays out. Client archives leave out hotkeys, character data, screenshots and logs unless you include them. Setup and the archive confirmation show exactly what is stored and what is left out, category by category.
  • Edits are verified. File Metadata writes to a copy, reads it back and checks it before it replaces a file, and can keep a verified backup.

  • Every message box has a Copy button and can be resized.
  • "1 file", "3 files" instead of "file(s)".
Known limitations

File Metadata reads but does not change PDFs, programs (changing them would break their digital signature), TAR archives, BMP/WebP/ICO and other image formats that would need re-encoding, camera raw files and Tibia client files.

Files made by the Assets Editor and Client Converter, and rebuilt client installations, are checked file by file but have not been tested in a running game client.

The program is not code-signed, so Windows SmartScreen may warn the first time it starts.

Get started in a minute

  1. DownloadOpen the latest release on GitHub and choose the portable zip or the folder zip.
  2. UnzipExtract it into a folder of your choice, for example Documents\Tibia Foundry.
  3. StartRun TibiaFoundry.exe. It isn't code-signed, so Windows may show a SmartScreen warning the first time: choose More info → Run anyway.
  4. Choose your clientThe first-run setup shows the Default Live Client and Default Test Client that the Tibia launcher installed, with their version and state. You can also browse to any client folder.
  5. Set your nameIn Settings → Attribution, so it is recorded in every image you export.
  6. ExportFiles are saved in Documents\Tibia_Foundry. Click the “✓ Saved to…” message to open the folder.

Portable or folder edition?

Both have the same features and need no .NET installation.

Portable: a single TibiaFoundry.exe that keeps its settings, logs and client archive in a “TibiaFoundry-Data” folder next to it. Good for a USB stick or keeping everything together.

Folder edition: keeps its settings in your Windows user profile and its client archive in your local app data (you can move the archive in Settings).

Updating to a new version

Download the new zip and unzip it into a new folder. Your settings are upgraded automatically. With the portable edition, copy your old “TibiaFoundry-Data” folder next to the new TibiaFoundry.exe. Release notes are on the GitHub release page.

Help and support

Something does not work

  • Application → Diagnostics shows running and failed operations, the log, and a self-check.
  • Diagnostics → Report saves a privacy-safe report (user and computer names are masked).

After a Tibia update

  • The Compatibility page shows which features are affected.
  • An archived client version keeps working (Clients page).

Check a new PC

  • Run TibiaFoundry.exe --self-test report: it checks graphics, client files, sounds, file metadata and settings without opening a window.
  • Report problems on GitHub Issues.

Frequently asked questions

What is Tibia Foundry?

A free Windows desktop app that reads the files of your Tibia client and turns them into images, sounds and data for TibiaWiki and other fan projects. It also edits and converts client files and archives client versions.

What can I do with it?

Export animated GIFs of objects and creatures, color outfits, render houses and high-resolution maps, extract sounds and sprites, build an item name catalog, generate NPC trade data, compare client versions, and keep and rebuild old client versions.

Is it free?

Yes. Tibia Foundry is free to download and use. It is a fan project by RockyLaRo.

Does it need an installed Tibia client?

It reads Tibia's client files, so you need either an installed Tibia client or a copy of a client or assets folder. The file scripts work on any files.

Does it change my Tibia client or the game?

No. It only reads the client's files on disk. It never writes into the client folder and never touches the running game.

Is there a portable version?

Yes. The portable edition is a single TibiaFoundry.exe that keeps all its data in a folder next to it. A folder edition is also available. Both have the same features.

Can it edit the metadata of my photos, music or documents?

Yes. Tools → File Metadata edits titles, authors, copyright, keywords, dates, GPS positions, music tags and document properties of JPEG, PNG, TIFF, GIF, MP3, FLAC, Ogg, M4A, WAV, MP4, MKV, Word, Excel, PowerPoint, EPUB and more, one file or many at once. PDFs, programs and some image formats are read only. Every save is verified, and backups are on by default.

Which operating systems are supported?

Windows 10 and Windows 11, 64-bit. It has been tested on Windows 11. There is no macOS or Linux version.

How do I install or update it?

There is no installer. Download the zip from the latest GitHub release, unzip it and start TibiaFoundry.exe. To update, unzip the new version into a new folder; settings are upgraded automatically. Portable users copy their TibiaFoundry-Data folder next to the new exe.

Where are my exported files?

In Documents\Tibia_Foundry, in a folder per kind (for example GIF_Exports). You can change each folder in Settings.

Why is my name in the exported images?

Tibia Foundry records the creator in each PNG and GIF's metadata (not as a visible watermark). Set your own name in Settings → Attribution.

Where can I find the source code?

The source code is distributed as a source package (TibiaFoundry-<version>-source.zip) alongside the program builds. The GitHub repository holds this website; program builds are published on its Releases page.

Tibia updated and something stopped working. What now?

Open the Compatibility page: it shows which features are affected. If you archived the previous client version on the Clients page, you can keep working with it.
