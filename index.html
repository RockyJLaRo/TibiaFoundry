Free Windows toolkit for Tibia fansites · Version 8.6.0

A graphics and content creation toolkit for the Tibia community.

Tibia Foundry is a free Windows desktop toolkit that helps Tibia fansite administrators, wiki editors, artists and content creators produce high-quality visual and informational resources.

Extract sprites, generate animated graphics, create outfit images, render houses and maps, explore Tibia game data, and prepare resources for your community projects — all from the Tibia client already installed on your PC.

  • Reads your official Tibia client and never changes it.
  • Works offline: no account, no telemetry, nothing uploaded.
  • Free, with no installer and no .NET to install: unzip and run.

What you can make

From a single item sprite to a complete map of Tibia: everything is read from the official Tibia client on your computer, previewed, and exported ready to publish.

Sprites and graphics

Browse every object, outfit, effect and missile in the client, and every creature and boss. Extract sprites and export individual items, creatures, effects and objects as images for articles and galleries.

Animated GIFs and outfits

Make animated GIFs of creatures and objects with the game's real frame timing. Color outfits, choose addons and mounts, and build outfit sheets for TibiaWiki and your own site.

Maps and houses

Render any house and its interior, one floor or all, as a PNG. Extract map tiles and build high-resolution maps of the game world at 25, 50 or 100 % zoom for location guides and articles.

Official Tibia data

Explore items, creatures, bosses, achievements, quests, areas and NPCs. Build an item catalog, export NPC trade tables, and see what each Tibia update changed by comparing client versions.

Sounds and content preparation

Play and extract the client's sounds and music as OGG or WAV for videos and guides. File scripts prepare large batches of exports, with a preview of every change before it happens.

Artwork credit and metadata

Exports record you as their creator. File Metadata edits titles, authors, copyright and keywords of one image or hundreds at once, with every save verified and backups on by default.

Credit your work and keep your artwork organized

Fansite galleries and wiki uploads grow quickly. Every PNG and GIF Tibia Foundry exports records its creator in the file's metadata, and the File Metadata page lets you add titles, keywords, authors and copyright notices to one file or hundreds — then check, compare and report on them.

  • Attribution without watermarks. Set your name once in Settings → Attribution; it is stored in each exported image's metadata, not drawn on it.
  • Presets for your site. Save your name, your fansite and a copyright line such as “Tibia graphics © CipSoft GmbH” as a preset, and apply it to a whole batch of exports.
  • Edit one file or hundreds. Select several files and type a value once, or build batch operations (set, remove, add or replace keywords, copy from a reference file) and preview them file by file before anything is written.
  • Every save is checked. Changes are written to a copy, read back and verified — the new values must be there and every other field unchanged — before the copy replaces the file. A failure leaves the file as it was.
  • Backups and honest results. Optional verified backups (restorable from Scripts → Backup and Restore), the modified date kept, files changed by another program never overwritten, and a result per file: saved, unchanged, not applicable or failed, with the reason.
  • Nothing removed silently. Removing authorship or copyright data is named before you confirm. Fields a format cannot store are refused and listed, never dropped. CSV and JSON reports cover any number of files.

Safe for your client and your files

Tibia Foundry only reads your Tibia installation. It never changes the client, never touches the running game, and never sends your data anywhere.

  • Read-only client. No tool writes into a Tibia client folder or the client archive; outputs there are refused.
  • No surprises with your files. Existing files are never replaced without asking, and replaced files go to a verified backup. File scripts preview every change and never delete.
  • Private by default. No account, no telemetry. The program goes online only when you import item data from TibiaWiki or use the optional asset download.
  • Personal data stays out. Client archives leave out hotkeys, character data, screenshots and logs unless you include them. Setup and the archive confirmation show exactly what is stored and what is left out, category by category.
  • Edits are verified. File Metadata writes to a copy, reads it back and checks it before it replaces a file, and can keep a verified backup.

File Metadata

  • View, edit, compare and batch-edit the metadata of your exported images and other media.
  • Presets for author, copyright and keywords; CSV and JSON reports.
  • Verified saving with optional backups.

Default clients

  • The Default Live Client (%LOCALAPPDATA%\Tibia\packages\Tibia) and the official Default Test Client (…\TibiaExternal) are recognized by name.
  • Setup shows each one's real state: available, incomplete or not installed.

Clearer messages

  • Setup's archive question and summary are organized in sections, with copyable paths.
  • Every message box has a Copy button and can be resized.
  • "1 file", "3 files" instead of "file(s)".
Known limitations

File Metadata reads but does not change PDFs, programs (changing them would break their digital signature), TAR archives, BMP/WebP/ICO and other image formats that would need re-encoding, camera raw files and Tibia client files.

After a Tibia client update, some features may need an update of Tibia Foundry; the Compatibility page shows which.

The program is not code-signed, so Windows SmartScreen may warn the first time it starts.

Get started in a minute

  1. DownloadOpen the latest release on GitHub and choose the portable zip or the folder zip. Check it against the SHA-256 checksum listed in the release.
  2. UnzipExtract it into a folder of your choice, for example Documents\Tibia Foundry.
  3. StartRun TibiaFoundry.exe. It isn't code-signed, so Windows may show a SmartScreen warning the first time: choose More info → Run anyway.
  4. Choose your clientThe first-run setup shows the official Default Live Client and Default Test Client that the Tibia launcher installed, with their version and state. You can also browse to any client folder.
  5. Set your nameIn Settings → Attribution, so you are credited as the creator of every image you export.
  6. CreatePick a creature, outfit, house or map area, preview it and export. Files are saved in Documents\Tibia_Foundry; click the “✓ Saved to…” message to open the folder.
Download for Windows
Portable or folder edition?

Both have the same features and need no .NET installation.

Portable: a single TibiaFoundry.exe that keeps its settings, logs and client archive in a “TibiaFoundry-Data” folder next to it. Good for a USB stick or keeping everything together.

Folder edition: keeps its settings in your Windows user profile and its client archive in your local app data (you can move the archive in Settings).

Updating to a new version

Download the new zip and unzip it into a new folder. Your settings are upgraded automatically. With the portable edition, copy your old “TibiaFoundry-Data” folder next to the new TibiaFoundry.exe. Release notes are on the GitHub release page.

Frequently asked questions

What is Tibia Foundry?

A free Windows desktop toolkit for creating Tibia graphics and reference material. It reads the files of the official Tibia client on your computer and turns them into sprites, animated GIFs, outfit images, house and map images, sounds and game data for TibiaWiki, fansites, guides and other community content.

Who is it for?

TibiaWiki editors and administrators, fansite administrators, Tibia artists and designers, content creators, and people who build tools and websites for the Tibia community — anyone who makes content about Tibia.

What can I make with it?

Animated GIFs of creatures and objects, outfit images with addons and mounts, outfit sheets, single sprites of items, creatures and effects, images of houses and their interiors, high-resolution maps and map tiles, item catalogs, NPC trade tables and other data exports, sound clips, and comparisons that show what a Tibia update changed.

Is Tibia Foundry official, or affiliated with CipSoft?

No. Tibia Foundry is an independent fan project by RockyLaRo, a TibiaWiki administrator. It is not affiliated with, sponsored or endorsed by CipSoft GmbH or Fandom, and images made with it are not approved by CipSoft.

Can I use the images I export on my fansite or wiki?

The graphics, sounds and data of Tibia belong to CipSoft GmbH, and Tibia Foundry gives you no rights to them. Whether and how you may publish them is up to CipSoft's rules for fan content, which you can find on Tibia.com. When you publish Tibia graphics, credit CipSoft GmbH — for example “Tibia graphics © CipSoft GmbH”.

Is it free?

Yes. Tibia Foundry is free to download and use, with no account, ads or in-app purchases.

Does it need an installed Tibia client?

Yes. It reads the official Tibia client's files, so you need the client installed with the Tibia launcher, or a copy of its folder. The live client and the official test server client are both recognized. The file scripts and File Metadata work on any files.

Does it change my Tibia client or the game?

No. It only reads the client's files on disk. It never writes into the client folder and never touches the running game.

Why is my name in the exported images?

Tibia Foundry records the creator in each PNG and GIF's metadata (not as a visible watermark), so your work stays credited when it is shared. Set your own name in Settings → Attribution. It records who made the export, not who owns the artwork, which remains CipSoft's.

Can it add copyright and keywords to my artwork?

Yes. Tools → File Metadata edits titles, authors, copyright and keywords of JPEG, PNG, TIFF and GIF images — one file or many at once — as well as tags of audio, video, Office and EPUB files. Save your details as a preset to reuse them. Every save is verified, and backups are on by default. PDFs, programs and some image formats are read only.

Why keep old client versions?

To preserve Tibia's history. The Clients page keeps an archive of the official client versions you choose, so you can still document how creatures, items and places looked before an update, and compare versions to see exactly what changed. Identical files are stored once, and personal data is left out unless you include it.

Where are my exported files?

In Documents\Tibia_Foundry, in a folder per kind (for example GIF_Exports). You can change each folder in Settings.

Which operating systems are supported?

Windows 10 and Windows 11, 64-bit. It has been tested on Windows 11. There is no macOS or Linux version.

How do I install or update it?

There is no installer. Download the zip from the latest GitHub release, unzip it and start TibiaFoundry.exe. To update, unzip the new version into a new folder; settings are upgraded automatically. Portable users copy their TibiaFoundry-Data folder next to the new exe.

Is there a portable version?

Yes. The portable edition is a single TibiaFoundry.exe that keeps all its data in a folder next to it. A folder edition is also available. Both have the same features.

Where can I find the source code?

The source code is distributed as a source package (TibiaFoundry-<version>-source.zip) alongside the program builds. The GitHub repository holds this website; program builds are published on its Releases page.

Tibia updated and something stopped working. What now?

Open the Compatibility page: it shows which features are affected. If you archived the previous client version on the Clients page, you can keep working with it.
