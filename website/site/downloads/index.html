First steps

  1. Install or unzip

    Run the installer, or unzip the portable edition anywhere.

  2. Set up

    The first start finds your Tibia client and asks how to keep client versions.

  3. Set your name

    Settings → Attribution: the creator written into every image you export.

  4. Create

    Open Home for workflows, or Content Studio → New project for a whole gallery.

What's new in 9.0.5

  • Version in the window header: the program's header now reads “Tibia Foundry v9.0.5” above its tagline, always taken from the build's own version.
  • One version, checked: the About page, file properties, installer and packages all report 9.0.5; an automatic check builds a later version and confirms that the header follows.
  • A new website: designed for phones first, in light and dark themes and five languages.
  • Tibia data online: characters, worlds, guilds, highscores, houses, kill statistics, creatures, spells, boosted bosses, fansites and Tibia news, provided by TibiaData.
  • New screenshots: every screenshot retaken from 9.0.5 in every language and theme, now including the About page.

Earlier in the 9.0 series

  • 9.0.4 – data that no longer depends on the language: item properties in catalogs and the categories of exported folders are the same in every interface language (existing catalogs are read correctly as they are), folders directly on a drive work, and the queue keeps running when a window fails.
  • 9.0.3 – stability: a damaged sprite sheet no longer closes the program from the Outfitter, and the Content Studio queue history stays small.
  • 9.0.2 – flavortext full stop: the infobox's flavortext now ends with the full stop the game adds on Look, exactly as TibiaWiki writes it.
  • 9.0.1 – flavortext: the object's look text from the client fills the infobox's flavortext.
  • TibiaWiki infobox exporter: {{Infobox Object}} for any object, from the client's own data (Appearances → Wiki infobox).
  • NPC trade in the infobox: npcvalue, npcprice, buyfrom and sellto from the client's trade data.
  • Every value labelled: client data, derived (review), TibiaWiki, or needs your input – nothing is guessed.
  • Batch infoboxes: one .txt file for every selected object, never replacing an existing file.
  • Safer saving: settings, catalogs and other documents are flushed to the disk before they replace the old file.
  • Backups across drives: a file moved into a backup on another drive is deleted only after its copy is verified.
  • Seamless upgrade: your 8.8 settings, library, client archives and item catalogs carry over unchanged.
