New in 9.0.2 · TibiaWiki infoboxes

An item article's infobox, filled from the client

Select an object in Appearances and open Wiki infobox: Tibia Foundry writes TibiaWiki's {{Infobox Object}} from the official client data, following the template's own parameters and the wiki's conventions. Review it, add what only you know, and paste it into the article.

  • From the client: ID, names, look text (flavortext), slot, level and vocations, hands and weapon type, imbuement slots, upgrade class, object flags, light and map colour, stackable and marketable.
  • NPC trade: the best NPC buy and sell prices and every trader, with their own price where it differs.
  • Nothing invented: every value shows where it came from; implemented, weight, attack, armor and the other values the client does not hold are listed for you to fill in.
  • Edit, copy, save: change any value, add more parameters, copy the markup, save it as .txt, or save one file for every selected object.

Asset Library

Find any resource in seconds, never lose one again

Your sprites, GIFs, renders, maps, sounds and artwork in one searchable place. Files stay where they are; the library only reads them.

  • Automatic: every file any tool exports is added in the background, with the tool and client version it came from.
  • Search and filter: by name, game ID, category, client version, tag, format, size, date and more.
  • Organize: your own categories, tags, custom fields, related assets and shareable collections.
  • Duplicates: identical files, the same graphic at another size and look-alike images are reported – nothing is ever deleted for you.
  • Safe: fast rescans, earlier versions of changed files, an integrity check, backup and restore – all stored locally and fully offline.

Safe by design

Your client and your files stay yours

Read-only on Tibia

The client folders are only read. Editors save copies elsewhere, and no tool writes into a client or archive folder.

Nothing half-done

Exports are written to a temporary place and moved into position only when complete; replaced files can be backed up and restored.

Local and private

No account, no cloud. TibiaWiki is contacted only by features that need it. Diagnostics reports leave out personal paths, so they are safe to share.

Release notes

What's new in 9.0.2

  • 9.0.2 – flavortext full stop: the infobox's flavortext now ends with the full stop the game adds on Look, exactly as TibiaWiki writes it.
  • 9.0.1 – flavortext: the object's look text from the client fills the infobox's flavortext.
  • TibiaWiki infobox exporter: {{Infobox Object}} for any object, from the client's own data (Appearances → Wiki infobox).
  • NPC trade in the infobox: npcvalue, npcprice, buyfrom and sellto from the client's trade data.
  • Every value labelled: client data, derived (review), TibiaWiki, or needs your input – nothing is guessed.
  • Batch infoboxes: one .txt file for every selected object, never replacing an existing file.
  • Article names from TibiaWiki: with the wiki's item list cached, "name" is the article title.
  • Safer saving: settings, catalogs and other documents are flushed to the disk before they replace the old file.
  • Backups across drives: a file moved into a backup on another drive is deleted only after its copy is verified.
  • Steadier controls: number fields no longer step twice per click after a theme switch.
  • One version everywhere: the program, installer, packages and this site all say 9.0.2.
  • Seamless upgrade: your 8.8 settings, library, client archives and item catalogs carry over unchanged.

FAQ

Questions and answers

Is Tibia Foundry free?

Yes. It is a free, independent community project with no account, no advertising and no paid features.

Does it change my Tibia client or my characters?

No. Tibia Foundry only reads the client's files. It never writes into a client folder, never touches your character, hotkeys or account, and does not interact with the game while it runs.

Where do the images come from, and may I publish them?

From the official client installed on your computer. Tibia's graphics and data are © CipSoft GmbH; Tibia Foundry writes that notice and your name as creator into every exported image. Follow CipSoft's rules for fansites and your website's own image policy.

Is the Asset Library uploaded anywhere?

No. The library is a SQLite database on your computer; your files stay where they are and are only read. Removing an asset from the library never deletes a file. Back it up or restore it from the library's Folders and storage tab.

Will it delete my duplicate images?

No. Find duplicates lists identical files, the same graphic at another size and look-alike images so you can decide what to keep. Nothing is deleted, moved or merged by the program.

Can I use it for my own fansite rather than TibiaWiki?

Yes – that is what publishing profiles are for. Create a profile with your sizes, formats, file names, folders, credit line and HTML or BBCode snippet; the TibiaWiki profile is just one example.

What happens after a Tibia update?

When it starts, Tibia Foundry checks the installed client in the background and offers to archive the new version. The Compatibility page reports how well the new files are understood, and an update-resources project renders everything new or changed since the previous version.

Which edition should I choose?

The installer for a normal installation with a Start-menu entry and uninstall; the portable edition to run it from any folder or USB stick without installing. Both are the same program.

Is Tibia Foundry affiliated with CipSoft or Fandom?

No. It is an independent community project and is not affiliated with or endorsed by CipSoft GmbH or Fandom. It is not part of CipSoft's Fansite Programme.
