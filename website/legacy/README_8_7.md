## Publishing (when you decide to)

Nothing has been pushed. To publish with git:

```bash
git clone https://github.com/RockyJLaRo/TibiaFoundry.git tibiafoundry-site
```

Copy `site/index.html` and `site/sitemap.xml` over the clone's files, then:

```bash
git -C tibiafoundry-site commit -am "Website for Tibia Foundry 8.6.0"
```

```bash
git -C tibiafoundry-site push origin main
```

GitHub Pages republishes within a minute or two. Or use GitHub's web interface: *Add file → Upload files*, drop `index.html` and `sitemap.xml`, commit to `main`.

**Download links:** they point to `releases/latest`. Until a release exists there, visitors see an empty Releases page (the page says so). To make them work, create a release `v8.6.0` and attach `TibiaFoundry-8.6.0-portable-win-x64.zip`, `TibiaFoundry-8.6.0-win-x64.zip`, `SHA256SUMS.txt` and, if you want to publish it, `TibiaFoundry-8.6.0-source.zip` from `dist/`.

**Screenshot note:** the setup screenshot shows this PC's real Tibia folder path (`C:\Users\Rocky\AppData\Local\Tibia\packages\Tibia`). Replace it before publishing if you prefer not to show it.
